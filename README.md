# Kashi App - Plataforma Web Oficial

Plataforma interactiva para el fortalecimiento empresarial, turístico y patrimonial de Riohacha y La Guajira, desarrollada bajo el marco de la Universidad de La Guajira (CEIDE) - Programa de Negocios Internacionales.

## Características
- 🗺️ **Mapa Interactivo de Riohacha (Leaflet.js)** con monumentos y comercios georreferenciados.
- 📷 **Módulo de Realidad Aumentada (AR)** para patrimonio cultural (Monumento al Palabrero / Pütchipü'ü, Los Embarradores, Muelle Turístico).
- 🌐 **Soporte Trilingüe**: Español, Inglés y Wayuunaiki nativo.
- 🏢 **Planes Comerciales**: Básico (9.900), Intermedio (9.900) y Premium (99.900).
- 👤 **Perfiles Funcionales**: Perfil de Turista/Explorador y Dashboard Empresarial con conmutador de planes.
- 📋 **Registro Dual**: Turistas vs. Empresas con validación de Matrícula Mercantil de Cámara de Comercio.
